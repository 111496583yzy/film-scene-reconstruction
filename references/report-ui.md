# 拉片工作台：界面与交互约定

目标不是把所有文字缩小塞进一屏，而是让**观看、换镜、理解、回看依据**这条工作流不离开同一个屏幕框架。主要目标视口为 1366×768 及以上；窄屏与高倍缩放保留功能和可读性，不为“一屏”截断内容。

## 依据与取舍

- [Apple HIG：Layout](https://developer.apple.com/design/human-interface-guidelines/layout?changes=lat_3__1_2)：参考信息层级、对齐、分组与渐进展开。
- [Claude Code：Interactive mode](https://code.claude.com/docs/en/interactive-mode)：参考快捷键与按需展开详细信息；不把交互文档说成完整视觉设计规范。
- [Lucide 可访问性](https://lucide.dev/how-to/accessibility)：图标配文字或明确名称，不要求用户猜图标。
- [Lucide 许可](https://lucide.dev/license)：ISC 与 Feather 派生图标的 MIT 通知。SVG 已从官方发布的 lucide-static 包联网取得，并按版本和 SHA-256 固定在 assets/vendor/lucide；报告内嵌，不依赖 CDN。

## 设计笔记（2026-10 精致化改版）

1. Apple HIG Color：色彩只用于主操作与状态；每个自定义色都有浅/深两套。本页中性灰阶为主，强调色浅色用低饱和蓝 #0a66d8，深色直接白色；禁用绿色系。
2. HIG Materials：顶栏/底栏用半透明毛玻璃（backdrop-filter）作为“控制层”，内容层（原片、三维）保持不透明，形成前后层级。
3. HIG Motion：动效只回应用户操作，120–220ms，cubic-bezier(.2,0,0,1)，全部包在 prefers-reduced-motion:no-preference 内。
4. HIG Layout：4/8/12/16/24 间距栅格，相关控件就近成组，对齐边线统一。
5. Anthropic/Claude 界面：克制、发丝级分隔（1px 半透明）、单一强调色、以背景色阶而非阴影/边框建立层级。
6. Linear / Raycast / Vercel：中性黑白灰、iOS 式分段控件与开关、胶囊状态标签、精致的浮层（toast、提示）。
7. Frame.io 类审片工具：媒体是唯一视觉焦点，播放是唯一强填充按钮；时间码 tabular-nums。
8. 格式塔：接近性（工具贴着所属画面）、共同区域（卡片背景）、相似性（同类标签同形），尽量不用边框。
9. 深色 = 纯黑 #000 背景 + #0f0f10 面板 + 白/灰文字；浅色 = #f4f4f5 背景 + 白面板。灯位暖金、机位雾蓝，低饱和且可区分。
10. 对比度：正文与次要文字 ≥4.5:1（浅色 --muted 6.3:1、--faint 5.1:1；深色 --muted 7.4:1、--faint ≥4.9:1）。

## 第二轮细节精修约定

- 动效令牌：--d1..--d4 = 90/140/220/320ms；--ease-standard、--ease-emph、--ease-exit、--ease-spring（linear() 弹性）。只做反馈性动画，全部在 prefers-reduced-motion:no-preference 内。
- 尺寸：按钮 36（主操作）/32（图标按钮，圆形 hover 底）/28（胶囊、分段、页签、开关）；标题栏 44px、状态栏 32px、面板内边距 16/12。
- 字阶：正文 13/20、次要 12/16、标题 15/22；时间码、编号、计数使用 mono 11px + tabular-nums（借鉴 Claude Code 的等宽小标签）。
- 焦点：双层环（面板色间隔 + 半透明主环）；tooltip 为自定义气泡，400ms 延迟，带快捷键 kbd，原生 title 会在运行时转成 data-tip。
- 状态：推测/方案/画面可见/未确认统一为「小圆点 + 文字」，不用色块。
- 进度条：4px 轨道，悬停/拖动/键盘时 6px；滑块悬停才出现；含已缓冲、镜头边界刻度、分段气泡（镜头名 + 时间）、点击脉冲。
- 镜头卡片：hover 抬升 1px；当前项描边环；切换时短暂高亮；播放中底部 2px 细进度条。
- 页签、分段控件共用滑块指示，弹性平移；claim 折叠用 ::details-content 高度过渡（不支持的浏览器直接展开）。
- 滚动条细、圆角、仅悬停显示。

## 布局所有权

- HTML / CSS / 客户端逻辑在 `assets/scene-report.html`、`scene-report.css`、`scene-report.js`。
- 可独立测试的时间与导航模型在 `assets/ui-state.cjs`；页面播放状态仍以同一个 video 元素为准。
- `scripts/scene-report.mjs` 验证并内嵌图标、样式、状态模型、三维渲染器和数据。
- UI 改动不得顺便改影片切点、人物轨迹、光线结论或三维场景数据，也不应通过隐藏未确认信息让分析显得更确定。

## 一个屏幕框架

1. 顶栏只放标题、素材摘要、说明、帮助、主题和侧栏入口。
2. 主区是原片与真正的三维对照。三维观察方式、灯位开关与三维内容放在同一个容器，按接近性分组。
3. 右侧只显示当前镜头，分析 / 证据 / 灯位 / 说明按页签切换；正文在侧栏内部滚动，不把所有分析卡片铺成长页面。
4. 底部常驻播放、总进度和镜头缩略列表。缩略列表是导航，不假装每个等宽卡片代表相同时长；真实时间由进度条和时间码呈现。
5. 窄屏一次显示原片或三维，切换按钮状态与实际显示必须由同一个状态函数同步。退出专注三维恢复原先选择。

## 分组、圆角与字重

- 使用间距、对齐与共同容器形成格式塔分组；不靠多层厚边框、装饰阴影或重复标签建立层级。
- 设计令牌集中在 scene-report.css 顶部（间距 --s1..--s6、灰阶 --g0..--g9、字号 --fs-*、圆角）。容器圆角16px、内嵌媒体舞台14px、按钮10px、缩略图8–10px，状态标签/计数/证据时间为全圆胶囊；无直角裸边。
- 用系统字体；正文13px用于密集工作台，次要文字以12px为主。不要靠降低到难读字号实现一屏。
- 三维观察方式是带滑块的分段控件，灯位/其他机位是 toggle switch；当前镜头卡片用前景色描边环 + 轻微放大，切换时自动滚动居中。
- 侧栏顶部有可关闭的新手引导（1 选镜头 → 2 机位视角 → 3 证据，点步骤可直接执行），关闭记入 localStorage（不可用时仅本次隐藏）；窄屏隐藏引导但保留「推演示意」入口。
- 进度条为细轨 + 圆形滑块 + 已播放填充，悬停显示时间提示。
- 三维画布背景为中性近黑/浅灰，标签为圆角胶囊、中性配色；场景数据自身的材质颜色不改。
- 只有播放是主要填充操作，其余按钮安静处理。选中状态同时有背景/形状和文字语义，不只靠色彩。

## 反馈与键盘

- 证据按钮使用可理解的时间而非只有内部编号。跳转后同时更新原片、三维、当前镜头和时间，并短暂显示结果反馈。
- 媒体不可用时仍可查看关键帧与分析，反馈应说“已显示分析”，不能假称视频跳转成功；提供选择视频的恢复入口。
- Space 播放/暂停、左右键换镜；输入框、按钮、三维画布和页签保留自身键盘行为，不抢键。
- 页签使用 roving tabindex 和方向键；镜头导航保留原生按钮、当前状态与方向键。所有图标操作都有名称与焦点样式。
- 帮助使用原生 dialog，Esc关闭并返回触发器。专注三维可用Esc返回。

## 动画与主题

- 高频动作只作短暂颜色反馈；页签内容轻微淡入，播放/暂停等图标交叉过渡，按钮按下轻微缩放。
- 动画只在 prefers-reduced-motion:no-preference 下启用；没有装饰性自动运动，首次载入不播放入场动画。
- 主题切换即时完成，不把整页颜色拖成长动画。浅色文字选区必须实际拖选检查；默认不禁用正文选择。

## 第三轮：动效与详情面板约定
- 弹簧 token（scripts/gen-springs.mjs 采样阻尼谐振子生成 linear()，不支持时回退 cubic-bezier）：snappy ζ0.63 约 8% 过冲 344ms；bouncy ζ0.48 约 18% 过冲 433ms；smooth ζ1 无过冲 460ms。
- 只动 transform/opacity（折叠用 grid-template-rows），will-change 仅在动画期间设置；全部写在 prefers-reduced-motion:no-preference 内，减少动态时退化为即时+淡入。
- 详情面板：镜头号/机位/时长徽标同行；置信度三格条（画面可见3/推测2/方案1/未确认0），文字标签保留；分区收起时显示首句要点，展开时首句加粗前置；正文限制 36em 行长；时间码 chip 按下回弹并在进度条落点闪烁。
- 引导三步在对应操作完成后显示 ✓ 完成态；点击步骤给目标控件涟漪脉冲。
- 3D：同一相机内的视角/镜头切换用约 450ms easeOutCubic 过渡，标签 220ms 淡入；不改变终点位姿数据。
