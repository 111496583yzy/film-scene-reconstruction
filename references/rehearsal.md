# 排戏模式（首期）

## 目标与边界

把只读拉片复制成独立的可编辑方案：摆人物与摄影机、设置起终点、播放预演、撤销、保存工程、导出分镜图/走位图/可播放页面。原片分析、证据和机器时间轴不能被编辑覆盖。参考照片只保存为造型参考，不宣称已经重建成可自由转动的真人模型。

## 所有权

- `assets/rehearsal/project.cjs`：唯一可编辑工程模型、校验、命令和撤销历史；人物资料全工程共用，站位和摄影机按镜头独立保存。
- 布景默认只改当前镜；场景共用时先复制，不静默影响其他镜头。明确选择同步时才修改共用布景。
- `assets/scene-editor3d.mjs`：Three.js 的选择、地面拖拽、选中提示、运动路线和截图能力；观察相机与拍摄机位分别处理。
- `assets/rehearsal/controller.js`：界面只是工程的投影。片场视图、机位画面、属性和时间线都读同一份工程，不各存坐标。
- `scripts/rehearsal.mjs`：离线新建/校验/导出独立排戏页。浏览器的本机草稿仅作恢复缓存，工程下载才是可移交的保存副本。

## 验收条件

1. 报告可从当前镜头复制排戏，也能新建空白/示例方案；原分析数据不变。
2. 人物和摄影机可拖动，属性能同步两个视图；观察旋转不改变拍摄机位。
3. 起终点及用时能播放；复制/删除/调整镜头时保持人物资料和镜头站位分离。
4. 撤销/重做、拖拽取消、无效导入与保存失败不会破坏当前工程。
5. 工程下载后重新打开，站位/镜头/动作与参考图保留；分镜图、走位图和可播放页面实际导出。
6. 独立 HTML 不依赖网络、API Key、业务工程依赖或原视频；不自动调用生成模型。
7. 深浅主题、浅色鼠标框选、窄屏查看、原有拉片播放/换镜/证据跳转实际回归。

## 不属于首期

照片自动变三维、任意三维模型/骨骼导入、精细表演、物理灯光标定、自动AI成片、多人同时编辑。相对坐标不是米，预演不是摄影测量结果。
