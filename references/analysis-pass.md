# 一批镜头怎么看

先看 a / b 联系表，再为机位变化、漏切候选和光线疑点补连续帧。填景别、类别、运镜、具体画面。只依据可见线索描述，不用“很有电影感”等空话。

- 景别由人物或物体的画框占比判断，不由虚化或焦距判断。
- 运镜先跟踪固定背景、前后景视差，再排除主体运动、裁切和防抖。a / b 相同不能证明中间没动；差分低也不能证明机位固定。
- 候选切点需要视觉复核；一个长镜不因“太长”而被判漏切。
- 同机位回切也要描述动作进度差异，不复制同一句画面描述。
- 没有可核对的声音 / 字幕就不编台词。人物编号是人工连续性标注，不做身份识别。
- 镜头占比、时长和切次是描述统计，不能单凭这些数据宣判剪辑好坏或人物作用。

不改机器字段；不确定运镜写 `unknown` 和 note。场景推演按 [inference-guide.md](inference-guide.md) 做跨镜证据分析。
