# 反推拍摄现场：用哪些线索，何时停止

## 1. 先分清四种陈述

- **观察**：在某镜某帧，人物右颊比左颊亮，地面影子朝画面左侧。能回到原图找到。
- **推测**：可能存在画面右侧、相对较高的来光。必须写依据；来光不一定是灯，也可能是窗或反射。
- **复拍方案**：如果我们要做出近似效果，可从该方向加柔光，检查鼻影后再调整。这不是声称原剧组这样做。
- **未知**：灯具型号、真实功率、精确色温、焦距、机高等不能由现有证据唯一确定。写未知不是失败。

可信度是分析者判断，不是机器测出的概率。“高可信度”也不等于片场史实。引用博主的灯位或焦距时，用 author 证据、保留来源，不把其示意图当作电影帧的独立验证。

## 2. 场景先于摄影机

选稳定锚点：门框、墙角、舞台边缘、柱子、固定窗、地面接缝。先画它们的相对拓扑和可见 / 未见区域，再放人物与摄影机。座位、桌椅可能移动，人物更不能当固定标尺。

默认用场内“入口侧 / 舞台侧 / 图左”命名，不声称真实地理方向。图上的方位和画框左右是两回事；记录镜面反射、倒置、旋转或后期翻转的可能性。跨房间、换景或明显布景变化要分 sceneId，不为一个统一图而硬拼。

没有已知尺寸与可靠标定时，坐标只有相对意义：图中的数值不是房间长宽、机位距离或人的真实身高。

## 3. 机位：由遮挡和透视约束位置，不由景别猜距离

- 先判断镜头朝向了哪些锚点，再看门框、人物、家具的遮挡顺序，排除不可能的机位区域。
- 反打与回切提供约束，但不保证摄影机严格镜像对称；布景拆墙、换位补拍、焦距变化都可能存在。
- “同一个背景”仅说明取景有关系；复用 setupId 需要位置与朝向可同时解释多镜。不足时分候选机位或留空。
- 近似平视 / 仰视 / 俯视是画面线索；没有场景尺度就不换算精确机高。
- 摄影机箭头表示推演朝向。只有明确标注的视角参数才画真实推测的三维视锥；若采用未标定显示角度，须通过 previewAngleDeg / proposal 明说，不偷偷冒充真实镜头视角。

## 4. 镜头：看见的是投影结果，不是 EXIF

相同画框可由多种焦距、距离、传感器尺寸及后期裁切组合实现。焦段倾向用“视野偏广 / 中等 / 偏窄”表达；虚化还受光圈、对焦距离、背景距离等影响，不等于长焦。

对有可靠标定的透视相机，水平视角与焦距、有效感光面宽相关；但这只是条件已知后的换算，不提供未知参数的答案。镜头畸变、变形宽银幕、呼吸效应、稳定和裁切会进一步影响简单模型。相关概念可核对 [Blender 相机手册](https://docs.blender.org/manual/en/2.90/render/cameras.html)，本 Skill 不要求安装 Blender。

区分镜头内变化时：

| 现象 | 优先检查 | 仍可能混淆 |
|---|---|---|
| 主体越来越大 | 前后景相对尺度、遮挡和透视是否变化 | 主体走近、推轨、变焦、数字放大 |
| 前后清晰度交换 | 固定物体边缘和焦点位置 | 变焦点、后期模糊、压缩 |
| 背景横向滑动 | 不同深度物体的相对位移 | 平移、摇镜、主体移动、防抖 |
| 轻微持续抖动 | 固定背景是否共同移动 | 手持、平台晃动、模拟抖动 |

两张关键帧不够时补中间帧；没区分出来就用 unknown，不编一条轨道。

## 5. 灯光：先记录结果，再提出能解释它的方案

按顺序检查：

1. 人脸、服装与背景哪些区域亮 / 暗；是否由材质颜色造成。
2. 鼻影、颏影、墙面与地面的投影方向；注意物体表面朝向。
3. 阴影边缘软硬与包裹程度；不要从柔和外观直接命名柔光箱型号。
4. 眼神光和反射高光；它们不一定一一对应独立灯具。
5. 可见窗户、实景灯、亮墙、天花反射是否能解释来光。
6. 换角度后亮暗是否一致；是否存在为特写重新布光、曝光变化、调色、局部遮罩或视效。

软硬首先描述影子的外观，不能唯一反解灯具。基础概念与复拍方法可查 [ARRI Lighting Handbook](https://www.arri.com/en/learn/lighting/lighting-handbook)；不把教学布光案例说成当前影片的现场记录。

每个拟放的灯位都要回答：它解释了哪条可见线索？为什么不是自然光 / 反射？放在这里是否与其他镜头矛盾？如果只知道方向不知道位置，不放一个确定点；在 lightNote 写来光方向，并保留位置未知。negative-fill 是减光方案，不画成发光的灯。

## 6. 跨镜反证与停止条件

每个机位组至少做一次回看：背景是否对得上、人物遮挡是否对得上、人物动了以后摄影机是否仍可解释构图。每个光源假设至少检查一个不同角度，做不到就降低可信度。

不用“人类常识”填缺失的门窗、天花灯和摄影机。新增证据仍不能收敛时，保留两个候选解释或未知，并说明需要什么资料来区分：原始宽画幅、更多反打、幕后照、场地图、摄影指导资料等。没有这些材料也能交付，只是如实呈现不确定性。

复拍建议描述可执行的相对操作和检查项，如“将主光移至人物侧前方，观察鼻影是否接近参考”，不用未经授权的型号、价格、模型能力或固定场地参数。
